# Product Requirements Document (PRD)
## MiCita - Comprehensive Appointment Management System

### 1. Product Overview

**Product Name:** MiCita (Agenda Gestión Clientes Pro)  
**Version:** 0.1.0  
**Platform:** Web Application (React/Node.js)  
**Target Market:** Small to medium businesses requiring appointment scheduling and client management  
**Primary Languages:** Spanish (primary), with English support  

### 2. Product Vision & Mission

**Vision:** To provide an all-in-one appointment management solution that empowers businesses to efficiently manage their client relationships, streamline booking processes, and establish a professional online presence.

**Mission:** Simplify appointment scheduling for businesses while providing clients with an intuitive booking experience through personalized microsites.

### 3. Product Architecture

**Frontend Technology Stack:**
- React 18.2.0 with functional components and hooks
- Tailwind CSS for responsive design
- Framer Motion for animations
- React Router for navigation
- Vite for build tooling

**Backend Technology Stack:**
- Node.js with Express.js server
- Supabase (PostgreSQL) for database
- Dual server setup (development/production)
- RESTful API architecture

**Third-Party Integrations:**
- Supabase (Database & Authentication)
- Bunny.net CDN (Image storage)
- SMTP via Hostinger (Email notifications)
- Google Maps API (Location services)
- Google OAuth (Social authentication)

### 5. Technical Specifications

#### 5.1 Database Schema
- **Users Table:** Authentication and profile information
- **Appointments Table:** Appointment details with status tracking
- **Clients Table:** Client information and contact details
- **Services Table:** Service offerings and pricing
- **Business Settings Table:** Configuration and preferences
- **Public Businesses Table:** Public directory listings
- **Gallery Table:** Image storage references

#### 5.2 API Endpoints
- **Authentication:** `/auth/*` - Login, signup, logout, password reset
- **Appointments:** `/api/appointments/*` - CRUD operations
- **Clients:** `/api/clients/*` - Client management
- **Services:** `/api/services/*` - Service management
- **Email:** `/api/send-email` - Email notifications
- **Public Businesses:** `/api/public-businesses/*` - Directory management
- **File Upload:** `/api/upload/*` - File handling
- **CSV Import:** `/api/import-csv/*` - Data import

#### 5.3 Security Features
- **Row Level Security (RLS):** Database-level access control
- **JWT Authentication:** Secure token-based authentication
- **CORS Configuration:** Cross-origin request security
- **Input Validation:** Comprehensive data validation
- **Environment Variable Security:** Secure configuration management
- **SQL Injection Prevention:** Parameterized queries

#### 5.4 Performance Optimizations
- **CDN Integration:** Bunny.net for image delivery
- **Database Indexing:** Optimized query performance
- **Caching Strategies:** Efficient data retrieval
- **Code Splitting:** Optimized bundle loading
- **Lazy Loading:** On-demand component loading
